> One named Win-Digipet session. Finish the switchboard. Leave a note the next person can read.

## How Win-Digipet Sits

Win-Digipet does not replace the command station, the bus wiring, or the locomotives you already own. It sits beside them as a named layout desk for one job: which digital control file is live, which switchboard still matches the locomotive list, and what the next person should read before the next session.

If two people share a layout PC, each keeps a Win-Digipet style of their own. Extra routes wait for their own title instead of crowding the live switchboard.

A first visit should be one short bus check, then the same Win-Digipet desk the next day. That is enough to see if the control file holds.

## Traffic Light

| Signal | On the Win-Digipet board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live locomotive list | Continue the same switchboard |
| Amber | Two routes mixed in one control file | Split the set before you run |
| Red | No title, no note, locos unlabeled | Stop and name the session first |
| Clear | Handoff written, live routes few | Close Win-Digipet and leave the desk |

## Open Order

1. Open the last Win-Digipet digital control, not a new empty layout desk.
2. Read the locomotive list and the last handoff.
3. Finish one visible switchboard route inside Win-Digipet.
4. Write what changed, then close with fewer unlabeled locomotives than you found.
5. If the set feels crowded, drop anything that belongs to a different Win-Digipet route.
6. Confirm Win-Digipet switchboard still talks to the bus on the layout you run.
7. Leave the layout desk title on the board before you close.

## After a Week

A week in Win-Digipet is not a larger unlabeled locomotive pile. It is the same title, a shorter live switchboard, and a note that still makes sense before the next session. Take finished routes off the live set so the next visit starts on the bus that is still open.

Other programs stay where they are. Win-Digipet only keeps the path back: desk name, digital control, locomotive list, handoff.

Leave Win-Digipet with a quieter layout desk than the one you opened. The next visit should start on that switchboard, not on a loose throttle pile.

## Sign-off

- [ ] The Win-Digipet workspace name is short enough to scan
- [ ] Only live locomotives are on the board
- [ ] A second person can read the handoff
- [ ] The last Win-Digipet file still opens after a restart
- [ ] Finished routes are off the live Win-Digipet set
- [ ] The Win-Digipet summary still matches the switchboard

## Field Note

Win-Digipet is easier to trust when the layout desk stays smaller than the locomotive folder it came from. Name the session, keep the live switchboard, finish one visible route, and write what changed.
